# Hello GitHub

这是我的第一个 GitHub 练习项目。

这个项目用来学习：

- 用 VS Code 编辑代码
- 用 Git 记录修改
- 把本地项目上传到 GitHub
- 用 README 说明项目内容

## 项目文件

- `hello-github/index.html`：网页结构和文字内容
- `hello-github/style.css`：网页颜色、布局和样式
- `hello-github/script.js`：网页按钮点击后的互动效果

## 如何打开

在电脑上打开这个文件：

```text
hello-github/index.html
```

然后点击页面里的按钮，查看互动效果。
